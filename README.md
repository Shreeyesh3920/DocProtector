# DocProtector
DocProtector is a full-stack document security and redaction application designed to help users identify and protect sensitive information within digital documents.

Users can upload documents, search for specific text or sensitive information, locate every occurrence within the document, and redact the identified content before downloading a protected version.

The application combines Angular for the frontend, ASP.NET Core Web API for backend services, SQL Server with Entity Framework Core for data management, and Python with PaddleOCR for intelligent text detection and localization.

Key Features
Secure user registration and authentication using ASP.NET Core Identity and JWT.
Upload and manage documents.
Search for specific text within documents.
Detect text locations using OCR.
Identify multiple occurrences of sensitive information.
Redact selected content from documents.
Download the protected/redacted document.
Store document and redaction metadata securely.
DocProtector aims to provide a simple and reliable way to identify, manage, and protect sensitive information in digital documents.
